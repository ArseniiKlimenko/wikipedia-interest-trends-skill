# Аналіз інтересу до астрономії на українській Wikipedia

## Резюме

На основі аналізу даних Wikimedia за період вересень 2024 – вересень 2026 років можна дійти **негативного висновку** щодо додавання курсу астрономії до вашого освітнього застосунку.

## Основні результати

### Ключові показники

- **Агрегований темп змін:** -55.7% (значне скорочення)
- **Статей із позитивним зростанням:** 1 з 8 (12.5%)
- **Статей із скороченням:** 7 з 8 (87.5%)
- **Коефіцієнт варіації:** 142.6% (висока волатильність)
- **Надійність тренду:** Низька

### Детальний аналіз по статтях

1. **Астрономія** (основна стаття): -51.5% (30,581 переглядів за 2 роки)
2. **Телескоп**: -76.3% (27,545 переглядів) - найбільший спад
3. **Планета**: -71.6% (52,846 переглядів)
4. **Сонце**: -67.8% (120,495 переглядів)
5. **Місяць**: -62.1% (7,451 переглядів)
6. **Орбіта**: -61.2% (13,143 переглядів)
7. **Зірка**: -16.7% (1,961 переглядів)
8. **Галактика**: +29.4% (45,345 переглядів) - єдина стаття з позитивним зростанням

## Причини, чому цим результатам можна довіряти? Чому не можна?

### Причини, чому можна довіряти

1. **Офіційне джерело:** Дані з Wikimedia API є офіційним, відкритим джерелом
2. **Дворічний період:** 730 днів спостереження дають достатньо часу для виявлення трендів
3. **Множинні статті:** Аналіз включає 8 різних астрономічних статей (репрезентативність)
4. **Консистентність:** 7 з 8 статей показують одну тенденцію (скорочення)

### Причини для скептицизму

1. **Висока волатильність (CV = 142.6%):** Це означає, що коливання від місяця до місяця переважають середній тренд. Коефіцієнт варіації > 100% вказує на ненадійність даних для прогнозування
2. **Малий розмір вибірки:** 8 статей – це обмежена вибірка (могло б бути 50-100+ статей)
3. **Відсутність контексту:** Спад може бути спричинений:
   - Загальним скороченням трафіку Wikipedia
   - Змінами в алгоритмах пошуку Google
   - Сезонністю та циклічністю інтересу
   - Технічними змінами на сайті
4. **Вибіркова хібність:** Користувачі Wikipedia можуть не представляти вашу цільову аудиторію

## Висновок і рекомендація

### ❌ НЕ РЕКОМЕНДУЄТЬСЯ

Додавати курс астрономії до застосунку на основі цих даних. Дані з Wikipedia вказують на **ЗНИЖЕННЯ**, а не на зростання інтересу.

### Альтернативні кроки

1. **Проведіть первинне дослідження:** Опитайте вашу цільову аудиторію про інтерес до астрономії
2. **Використайте множинні джерела:**
   - Google Trends для пошукових запитів
   - YouTube для аналізу популярності відео
   - Освітні платформи (Coursera, Udemy) для даних про записи на курси
   - Соціальні мережі для виявлення дискусій
3. **Розгляньте альтернативні теми:** Проаналізуйте популярні теми на Wikipedia, які показують зростання інтересу
4. **Впровадьте метрики для моніторингу:** Якщо все ж додасте астрономію, встановіть KPI для відстеження використання курсу користувачами вашого застосунку
5. **Стратегічна гнучкість:** Почніть з більш популярних предметів, отримайте дані про реальний користувацький інтерес, потім розширюйте каталог

## Висновок

На основі наявних даних Wikipedia **не рекомендується** розраховувати на растуче поле інтересу до астрономії в україномовної аудиторії. Для прийняття обґрунтованого рішення необхідне додаткове дослідження, яке враховує вашу специфічну цільову аудиторію та контекст.
