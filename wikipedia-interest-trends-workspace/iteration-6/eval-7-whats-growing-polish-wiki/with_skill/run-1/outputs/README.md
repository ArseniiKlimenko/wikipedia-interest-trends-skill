# Аналіз растущих тем польської Вікіпедії

## Основні знахідки

**Завдання**: Що зараз найбільше набирає інтерес у польськомовній Вікіпедії, окрім новин про знаменитостей? Шукаємо ідеї для контенту.

**Період**: Вересень 2024 — серпень 2026 (24 місяці)

### Топ растущих тем

1. **Бреттство Каплатського Святого Піуса X** — +114% відносного зростання (СЕРЕДНЯ впевненість)
2. **Параграй** — +68% (СЕРЕДНЯ впевненість)
3. **Кіт-д'Івуар** — +47% (СЕРЕДНЯ впевненість)
4. **Сенегал** — +30% (СЕРЕДНЯ впевненість)
5. **Марокко** — +26% (ВИСОКА впевненість)
6. **Мальта** — +13% (ВИСОКА впевненість)

### Контекст

- **Польська Вікіпедія в цілому** втратила 9% переглядів за цей період
- **87% читачів** з Польщі; 4% з США, 2% з Німеччини
- Всі ці теми растуть всупереч загальній тенденції падіння

## Файли в цій папці

### 📄 Головні документи

- **response.md** — Повна відповідь українською мовою (ЧИТАЙТЕ СПОЧАТКУ!)
- **report.pdf** — Однорядковий PDF звіт для презентацій (професійний вигляд)
- **summary.md** — Детальна статистична таблиця

### 📊 Графіки

- **trend.png** — Графік трендів для всіх 6 тем (місячна динаміка)
- **growth.png** — Графік показників зростання (порівняння росту)
- **daily.png** — Денні діагностичні дані

### 📁 Дані для аналізу

- **data.csv** — Місячні дані для кожної теми (для експорту в Excel/Sheets)
- **analysis.json** — Повна статистика в форматі JSON (для програмування)
- **discover.json** — Резултати пошуку (60 протестованих кандидатів)
- **discover.md** — Таблиця всіх 60 кандидатів з growth/confidence

## Як використовувати результати

### Для менеджерів контенту
1. Почніть з **response.md** — там вся інформація українською
2. Дивіться **trend.png** і **growth.png** для внутрішніх презентацій
3. Використовуйте сезонність (календар) для планування публікацій

### Для розробників/аналітиків
1. Експортуйте **data.csv** в Excel для своєї аналітики
2. Використовуйте **analysis.json** для інтеграції з BI-системами
3. Перевірте **discover.json** для повного списку 60 тем

### Для презентацій
1. Скористайтеся **report.pdf** — професійний однорядковий звіт
2. Вставте **trend.png** та **growth.png** в слайди
