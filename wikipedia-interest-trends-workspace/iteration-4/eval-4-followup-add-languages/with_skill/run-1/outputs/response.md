# Відповідь на запит про португальську та українську аудиторії

Дякую за уточнення! Я переаналізував дані з урахуванням португальської та української аудиторій, а також змінив вагування — тепер **зростання в два рази важливіше за розмір аудиторії** (growth=2 vs size=1).

## Що змінилось

**Рейтинг переписаний на основі росту:**
- **IELTS:** турецька (0,93) → в'єтнамська (0,81) → польська (0,64) → іспанська (0,52) → німецька (0,33) → українська (0,14) → португальська (0,12)
- **TOEFL:** турецька (0,95) → німецька (0,71) → в'єтнамська (0,64) → іспанська (0,55) → польська (0,33) → українська (0,19) → португальська (0,12)

## Ключові висновки

1. **Турецька — лідер за зростанням**
   - IELTS: +23% (95% ДІ [-6%, +68%]) — єдиний позитивний тренд, хоча довіра низька через широкий інтервал
   - TOEFL: -12% — найменший спад серед всіх розділів
   - Обидва тести займають перші місця в рейтингу при пріоритизації зростання

2. **В'єтнамська — стійка друга позиція**
   - Найбільша аудиторія (1 508 переглядів/міс. для IELTS)
   - Спад -19% (IELTS) менш крутий, ніж у більшості інших
   - Найвища інтенсивність (30,7 на 1M переглядів)

3. **Португальська та українська — найгірші тренди**
   - TOEFL (pt): -60%, довіра низька, дуже малий обсяг (~3 переглядів/день)
   - TOEFL (uk): -55%, довіра низька, дуже малий обсяг (~4 переглядів/день)
   - Найглибші спади серед всіх досліджуваних мов

## Рекомендація

При пріоритизації **зростання**:

1. **Турецька аудиторія** потребує подальшої перевірки, попри низьку довіру. Розширте період до 36 місяців для підтвердження, чи це справжній тренд.
2. **В'єтнамська аудиторія** залишається другим пріоритетом з стабільною базою та відносно малим спадом.
3. **Португальська та українська** непривабливі для інвестицій у контент за англійської мови, якщо зростання — основний критерій.
