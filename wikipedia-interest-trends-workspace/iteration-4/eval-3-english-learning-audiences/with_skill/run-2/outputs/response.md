# Звіт: Аудиторії для дослідження вивчення англійської мови на основі Wikipedia

## Усім резюме

На основі аналізу статей про IELTS та TOEFL на п'яти мовних розділах Wikipedia (польській, турецькій, іспанській, в'єтнамській та німецькій) виявлено, що інтерес до вивчення англійської **переважно знижується**.

### Рекомендації щодо аудиторій для дослідження:

#### 1. **Турецька аудиторія** (основний пріоритет)
- **Чому саме вона**: Серед усіх досліджених розділів турецька показує найкращий потенціал росту. IELTS турецькою демонструє +23% відносного росту (95% ДІ: -6% до +68%), хоча з низькою впевненістю. TOEFL турецькою показує найменший спад (-12%, низька впевненість).
- **Розмір аудиторії**: IELTS - 1,073 переглядів на місяць (~35 переглядів на день), TOEFL - 672 переглядів на місяць (~22 переглядів на день).
- **Інтенсивність**: Найвищі показники інтенсивності (9.9 та 6.2 переглядів на 1М просмотрів вікі відповідно).
- **Примітка про читачів**: Дані про розташування читачів обмежені (Туреччина витримується з причин безпеки), але останні англійські дані показують, що більшість читачів, ймовірно, проживають у Туреччині.

#### 2. **В'єтнамська аудиторія** (вторинний пріоритет)
- **Чому варто розглянути**: Це найбільша аудиторія серед досліджених розділів. IELTS в'єтнамською отримує 1,508 переглядів на місяць (~50 переглядів на день) з високою впевненістю в даних. Виконує роль якісного індикатора попиту, навіть попри спад.
- **Причина спаду**: IELTS показує -19% відносного росту (95% ДІ: -32% до -6%, висока впевненість). TOEFL показує -45% (95% ДІ: -54% до -36%, середня впевненість).
- **Чому дослідити**: Велика аудиторія робить її цінною для валідації попиту через вторинні сигнали. Варто з'ясувати, чи це глобальна тенденція на Вікіпедії, чи локальна причина.
- **Географія**: В'єтнам витримується з причин безпеки, але більшість читачів, ймовірно, проживають у В'єтнамі.

#### 3. **Іспанська та німецька аудиторії** (не рекомендуються як перші об'єкти)
- **Почему не рекомендуються**: Обидві показують чітке, статистично значиме падіння інтересу:
  - Іспанська: IELTS -36% (95% ДІ: -45% до -28%, середня впевненість), TOEFL -49% (95% ДІ: -59% до -37%, висока впевненість).
  - Німецька: IELTS -37% (95% ДІ: -46% до -30%, середня впевненість), TOEFL -40% (95% ДІ: -46% до -32%, середня впевненість).

#### 4. **Польська аудиторія** (низький пріоритет)
- Дуже мала аудиторія (IELTS - 287 переглядів/місяць, TOEFL - 125 переглядів/місяць) з низькою впевненістю в тенденціях.

## Методологія

**Період аналізу**: Останні 24 місяці (вересень 2024 - серпень 2026); порівняння останніх 12 місяців з попередніми 12 місяцями.

**Обмірювані теми**: 
- IELTS (Q490396) та TOEFL (Q487425) як прокси для "інтересу до вивчення англійської мови". Ці статті відражають навмисний інтерес учнів до вивчення англійської, на відміну від загальної цікавості до англійської мови.

**Мовні розділи**: Польський, турецький, іспанський, в'єтнамський, німецький.

**Критерій ранжування**: Поєднання розміру аудиторії, темпу росту та інтенсивності (кількість переглядів на 1 мільйон переглядів вікі).

**Довіра до даних**: Довіра оцінюється як висока/середня/низька на основі обсягу трафіку, стабільності тренду та наявності викидів. Відносний ріст = зміна частки топіка в усіх переглядах вікі.

## Важливі обговорення та обмеження

1. **Погіршення даних в 2025 році**: період включає оновлення виявлення ботів Wikimedia (травень-червень 2025), що може частково пояснити спади. Відносний ріст частково компенсує цей ефект.

2. **Цікавість ≠ готовність купувати**: Wikipedia показує цікавість читачів, але не гарантує комерційний попит. Рекомендується валідація через другий сигнал (тренди пошуку, ключові слова в App Store, тестування посадкової сторінки).

3. **Одна стаття для кожного топіка**: Аналіз базується на єдиній статті (IELTS або TOEFL) для кожної мови. Розширення корзини з пов'язаних статей може дати більш точну картину.

4. **Низька впевненість у турецьких даних**: Хоча турецька аудиторія показує найбільш оптимістичні показники, впевненість низька через широкі довірчі інтервали. Розширення періоду до 36+ місяців необхідно перед остаточним рішенням.

## Наступні кроки

1. **Розширте період аналізу**: Повторіть аналіз з 36+ місяцями для турецької та в'єтнамської аудиторій, щоб підтвердити стабільність тренду.

2. **Добавте пов'язані статті**: Для турецької та в'єтнамської аудиторій додайте 3-5 пов'язаних статей (наприклад, статті про мовні школи, програми обміну, мовні сертифікати) для розширення сигналу.

3. **Валідація через другі джерела**: 
   - Тренди пошуку (Google Trends, Yandex для турецької)
   - Ключові слова в App Store для додатків для вивчення мов
   - Тестування посадкової сторінки для визначення готовності користувачів платити

4. **Географічна глибина**: Для турецької та в'єтнамської аудиторій розглянути наступні кроки з метою розуміння демографії користувачів та їх покупівельної спроможності.
